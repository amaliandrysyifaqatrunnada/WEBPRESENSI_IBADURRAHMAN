💡 Cara Memasukkan ke Dokumen Laporan (Word / Google Docs / Canva):

  1. Klik tombol Download Gambar (PNG) di atas.
  2. Buka dokumen Microsoft Word atau Google Docs laporan Anda.
  3. Pilih menu Insert ➜ Pictures ➜ This Device, lalu pilih file Flowchart_Presensi_PKBM_Ibadurrahman.png yang baru diunduh.
  4. Atur ukuran gambar sesuai kebutuhan halaman laporan Anda. Resolusi gambar sudah sangat tajam (1300 × 1850 px) dan tidak akan pecah/buram.
